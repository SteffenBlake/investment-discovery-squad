# Synthetic acceptance artifacts

`acceptance-result.json` and `acceptance-alert.md` are reproducible **synthetic software tests**. They are not discoveries, backtested market strategies, real forward predictions, or real Dot delivery receipts.

Reproduce the JSON result with `python3 -m squad demo`. For the isolated test ledger and knowledge export, use `python3 -m squad demo --output-dir NEW_DIRECTORY`. Never point production monitoring at that directory.

Four distinct, disjoint synthetic forward events produce win, win, loss, win. This places the additional loss in the record before the third success and allows the first immediate qualification alert to contain the complete 3-of-4 result.

Actual Dot message transport is verified separately during onboarding using an explicitly labelled setup message. The synthetic alert preview is never sent as investment evidence. The instrument, test currency, allocation and UTC timestamps are fictional fixture inputs, never production defaults.
