name: squad-monitor
description: Evaluate investment signal forecasts, deliver newly qualified alerts, and monitor a configured investment discovery ledger on a native schedule.
---

Resolve SQUAD_REPO, actual central owner and required individual native SQUAD_* configuration from the saved thin invocation. Variables must actually reach that owner; prompt markers alone do not bind them. Read current checkout guidance. Run `python -m squad deployment check`; false current requires squad-reconcile before financial work. Missing graph/ledger or changed identity means stop and recover, never create substitutes.

Run `python -m squad run`. Inspect JSON/stderr even on nonzero exit. A failed feed must not suppress other queued alerts. Examine pending qualifications and uncertain deliveries before research/summaries.

For each pending alert: claim --alert ID. Null means already owned/delivered. Deliver the returned complete message immediately through the configured supported native destination, even without an entry opportunity. Preserve every live success/loss/pending attempt, dates, mechanism, historical result, horizon, uncertainty and limitations. Attach complete record if message limits require; do not omit losses.

After actual delivery: ack --alert ID --token TOKEN --receipt ACTUAL_RECEIPT. A worker log/file is not delivery proof. Confirmed rejection before send permits release with actual confirmed-not-sent evidence. Unknown delivery stays claimed; inspect actual destination history before ack/release. No automatic claim expiry or blind resend. Qualification/outbox creation is atomic; external exactly-once delivery needs reconciliation/idempotency.

Contrary evidence requires explicit DEGRADED/INVALIDATED with reason; never manually qualify or edit SQL/history. Use squad-trades for actual portfolio questions/fills. Routine unchanged runs stay quiet; report persistent feeds/runtime/missed execution/delivery failures. Missing endpoints remain pending.

After alerts, run backup-due: full Ladybug export + SQLite online backup + originals, uploaded/downloaded and restore-tested in private Drive. Local snapshot is not cloud durability. Preserve pending upload state on ambiguous responses. Report auth/quota/verification failures; no unapproved spending or evidence deletion. Reconciliation checks actual native enablement; a cached receipt alone proves neither future execution nor device push.
